# python-devcontainer

A template for new Python projects, that I normally use, featuring [DevContainer](https://containers.dev), [uv](https://docs.astral.sh/uv/) and [Pi Coding Agent](https://pi.dev). Also, some agent harness template files that I learned from [walkinglabs@learn-harness-engineering](https://github.com/walkinglabs/learn-harness-engineering).

## Features

- [x] [DevContainer](https://containers.dev) running Fedora-minimal and Python 3.14 (latest).
- [x] [uv](https://docs.astral.sh/uv/) for package, dependency and Python virtual environment management.
- [x] [ruff](https://docs.astral.sh/ruff/formatter/) for code formatting and linting.
- [x] [pytest](https://docs.pytest.org/en/stable/) for testing Python code.
- [x] [Dockerfile](https://docs.docker.com/build/concepts/dockerfile/) for configurations and deployments of DevContainer. Maybe others as well...
- [x] [Pi Coding Agent](https://pi.dev) for a coding companion, ofc.

## Setup

The setup is pretty straightforward, and things are up and running within just a minute of initial spin-up. You can follow these steps:

1. **Use this template**
2. **Clone the repository**
3. **Re-open the container**
4. **Wait for setup to finish**
5. **Now, we go full force (♡°▽°♡)**
